# Tile Launcher 2.3.0 (85) 회사 시험 안내

기본값 역할과 수동 선택을 분리하고, 설정의 프로필 편집 대상·추가/복제 이름 창을 개선한 시험본입니다. 기존 메뉴 경로 UI와 2.1.11의 두 버그 수정도 포함합니다. 회사 Mac에서 보고된 R389 자동 선택 문제의 원인이 확정됐거나 해결됐다는 뜻은 아닙니다. 정식 채널은 2.1.10을 유지합니다.

## 먼저 업데이트하고 새 프로세스로 실행

Tile Launcher 메뉴에서 정상 종료한 뒤 실행합니다.

    brew update
    brew upgrade --cask colah16/tap/tile-launcher@dev

평소 설치 위치의 Tile Launcher를 다시 여세요. 기존 @dev의 앱 위치와 설정을 유지하며, 두 채널을 함께 설치하거나 설정을 지울 필요가 없습니다. 강제 종료하지 마세요. 새로 실행한 앱의 버전이 2.3.0 (85)인지 확인합니다. 업데이트나 종료가 실패하면 반복 실행하지 말고 표시된 상태를 알려주세요.

## 참고용 전체 UI 확인 순서

아래는 업데이트 완료 후 진행할 시험 항목입니다. 원치 않는 시험용 변경은 등록 탭의 변경 취소로 되돌릴 수 있습니다. 저장한 기본값 변경은 실제 설정에 적용되므로 원래 값을 기억해 두세요.

1. 설정의 등록 탭에서 편집할 프로필을 바꿉니다. 편집 대상 변경만으로 현재 런처의 수동 선택이나 자동 선택 상태가 바뀌지 않는지 봅니다. 집중 모드 변화로 편집 대상이 옮겨 가지 않는지도 확인합니다.
2. 원하는 프로필에서 **기본값으로 설정**을 누릅니다. 기본 표시와 삭제 보호를 확인하고, 저장 전에는 기존 실행 상태가 바뀌지 않는지 봅니다. **변경 취소**하면 돌아오고, 다시 지정한 뒤 **저장**하면 지정 기본값이 유지되는지 확인합니다. 저장/취소는 해당 탭 편집본에 적용되며 탭을 오가도 미저장 편집은 보존됩니다.
3. **빈 프로필 추가…**와 **이 프로필 복제…**를 눌렀을 때만 이름 창이 나오는지 확인합니다. 빈 이름은 확인할 수 없고, Esc/취소는 프로필을 만들지 않아야 합니다. 복제 확인 시 버튼을 누른 편집 프로필의 항목이 복사되고 새 편집 대상만 선택됩니다. 원치 않는 시험용 추가는 저장하지 말고 변경 취소하세요.
4. Focus 필터의 새 프로필 선택 후보에서 저장된 기본값이 제외되는지 확인합니다. 저장 전의 기본값 지정은 후보 목록을 바꾸지 않습니다. macOS가 이전 후보를 잠시 표시할 수 있고, 이미 연결했던 기본 프로필 참조도 OS 설정에 남을 수 있습니다. 앱은 그 기본 역할을 Focus 선택으로 적용하지 않습니다. 이번 확인을 위해 기존 필터를 삭제·재등록할 필요는 없습니다.
5. 회사의 기존 **Work → 오마** 연결은 정상 매핑입니다. 자동 선택 상태에서 Work로 바꾼 뒤 완전히 닫고 다시 열어 기대한 프로필을 봅니다. Tile Launcher 필터 연결이 없는 구간에서는 **저장한 기본값**으로 돌아오는지 비교합니다. 다른 모드에 별도 연결이 있다면 그 연결 대상이 우선합니다. 예배에 연결이 있는지는 미확인이므로 ‘Work가 아니면 모두 기본값’이라고 가정하지 않습니다. 휠/Option 조합 임시 전환은 저장된 기본값 변경과 구분합니다.

## 문제가 남을 때만 선택적으로 진단

기본 실행은 진단을 기록하거나 관찰용 추가 Focus 조회를 하지 않습니다. 별도 실행 인자 없이 메뉴로 켤 수 있습니다.

1. 메뉴바 아이콘을 **우클릭 → 프로필 진단 시작**합니다.
2. 문제가 생긴 집중 모드 전환과 평소 Option 열기를 바로 반복합니다. R389 반례는 기존에 Tile Launcher 필터 연결이 없는 것으로 알고 있는 상태에서 **오버레이 프로필 메뉴로 기본값을 직접 선택 → 같은 메뉴의 집중 모드에 따라 자동 선택을 다시 켜기**까지 재현하세요. 이를 위해 기존 필터를 삭제할 필요는 없습니다. 기대한 프로필·실제로 표시된 프로필은 본인이 관찰해 알려주세요. 열린 고정 화면과 완전히 닫고 새로 연 경우가 다른지도 비교할 수 있습니다.
3. **프로필 진단 중지 → 프로필 진단 로그 폴더 열기**를 누릅니다. 중지가 비활성이면 자동 종료된 세션이므로 폴더만 여세요.
4. 그 회사 Mac에서 방금 만든 **profile-diagnostics-**로 시작하는 최신 파일을 첨부합니다. 확장자는 없습니다. 집 Mac으로 자동 전송되지 않으며 기존 로그도 덮어쓰지 않습니다.

한 세션은 최대 10분·1MiB·200건입니다. 이름·프로필 UUID·해시·앱/항목 목록·원시 오류문을 기록하지 않고 제한된 상태 범주·일치 여부·개수·시간만 남깁니다. 자동 업로드는 없습니다. 이 진단 포함 시험본은 정식 배포 대상으로 승격하지 않습니다.
