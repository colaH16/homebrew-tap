# Tile Launcher 2.2.0 (84) 프로필 진단 시험

회사 Mac의 집중 모드를 바꿔도 런처 프로필이 맞지 않는 원인을 확인하는 시험본입니다. 원인 수정 완료본이나 정식 공개용 앱이 아닙니다. 메뉴 경로 UI와 앞선 두 버그 수정은 유지합니다. 기본 실행은 로그를 기록하지 않습니다.

## 업데이트 후 새 앱 실행

    brew update
    brew upgrade --cask colah16/tap/tile-launcher@dev

기존 앱 위치와 설정은 유지됩니다. 업데이트 뒤 Tile Launcher를 메뉴에서 정상 종료하고 평소처럼 다시 여세요. 이미 실행 중인 이전 앱에 진단 기능이 추가되는 것은 아닙니다. 강제 종료하거나 설정을 초기화할 필요는 없습니다.

## 회사 Mac에서 짧게 재현

1. 메뉴바 Tile Launcher 아이콘을 **우클릭**하고 **프로필 진단 시작**을 누릅니다.
2. macOS 집중 모드를 기존 **Work** 또는 **예배**로 바꾸고, 평소처럼 Option으로 런처를 여세요. 기대한 프로필과 실제 열린 프로필이 다른지 확인합니다. 새 프로필을 만들거나 기존 필터를 다시 등록하지 마세요.
3. 메뉴바 아이콘을 우클릭해 **프로필 진단 중지**를 누른 뒤 **프로필 진단 로그 폴더 열기**를 누릅니다. 중지 항목이 비활성이면 세션이 이미 끝난 상태이므로 바로 로그 폴더를 여세요.
4. 열린 폴더에서 **profile-diagnostics-**로 시작하는 방금 만든 파일(수정 날짜가 최신인 파일)을 이 대화에 첨부합니다. 확장자는 없습니다. 실제로 시험한 회사 Mac의 파일이며 집 Mac에 자동으로 옮겨지지 않습니다. 기존 로그는 그대로 보존합니다.

별도 실행 인자는 필요하지 않습니다. 한 세션은 최대 10분·1MiB·200건으로 제한되므로 진단 시작 직후 재현하세요. 시간이 지나면 세션을 다시 시작할 수 있습니다. 이름·프로필 UUID·해시·앱/항목 목록·원시 오류문은 기록하지 않으며 자동 전송하지 않습니다. 로그에는 제한된 상태 범주·일치 여부·개수·시간만 남깁니다.
